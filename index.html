The problem

Your agent runs everything on the biggest model, and says “done” too early.

  • “Done” that isn’t done. The agent reports success, you find out later. The rework costs more than the original task.
  • Opus for everything. Renaming a variable, grepping for call sites, writing a test stub: all on the most expensive model, burning quota or money.
  • Picking models by hand is tedious. So nobody does it, per subtask, every time.
  • It scales the wrong way. Every parallel agent and every CI run multiplies the waste.

How it works

Cheapest model first. Check. Step up if it fails. Receipt for every step.

That loop never changes. What changes is how much Horsy is allowed to do, and it earns each step on your own repo.

01 · DAY ONE Zero risk

Verify

Every “done” gets checked before it is accepted. If the work isn’t there, you hear it now, not in code review.

02 · SHADOW Changes nothing

Shadow routing

Horsy watches your sessions and tells you what it would have routed, and what that would have saved. Your models stay exactly as they are.

03 · ACTIVE Per task type

Active routing

Turns on only for the task types where your repo’s data shows it costs less and breaks nothing. Everything else stays on your default model.

What a receipt looks like

One line per step. Model, cost, time, pass or fail.

Guarantees

Built so it never makes things worse.

These are product rules, not marketing. If it doesn’t pay off, it turns itself off.

  • Your main session is never touched.Only subagents get routed.
  • It never blocks you.If Horsy fails or is slow, everything runs as before.
  • Local and fast.Routing decisions run on your machine in tens of milliseconds. Only metadata leaves it.
  • Routes down only when it is cheaper.Expected cost and time, retries included, must be lower than staying put.
  • Turns itself off where it loses.Any task type where it isn’t paying off goes back to your default model.
  • You stay in control./horsy off, pin a model per task, one-line receipts.
  • Honest receipts.Net time, net cost, errors caught. Even when the number is negative.
  • Neutral.A model grading its own work has a conflict of interest. Horsy is an independent check, and later stages route to other providers and local models too.
