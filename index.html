The problem

Your agent runs everything on the biggest model, and says “done” too early.

“Done” that isn’t done

The agent reports success. You find out later. The rework costs more than the original task.

Opus for everything

Renaming a variable, grepping call sites, writing a test stub. All on the most expensive model, burning quota or money.

Nobody picks models by hand

Choosing a model per subtask, every time, is tedious. So nobody does it.

It scales the wrong way

Every parallel agent and every CI run multiplies the waste.

How it works

Cheapest model first. Check. Step up if it fails.

That loop never changes. What changes is how much Horsy is allowed to do, and it earns each step on your own repo.

01 day one · zero risk

Verify

Every “done” gets checked before it is accepted. If the work isn’t there, you hear it now, not in code review.

02 changes nothing

Shadow

Horsy watches your sessions and tells you what it would have routed, and what that would have saved. Your models stay as they are.

03 per task type

Active

Turns on only for task types where your repo’s data shows it costs less and breaks nothing. Everything else stays on your default.

The receipt

One line per step. Even when it lost.

Model, cost, time, pass or fail. When a step cost more than running Opus alone would have, the receipt says so.

Guarantees

Built so it never makes things worse.

These are product rules, not marketing. If it doesn’t pay off, it turns itself off.

Main session untouchedOnly subagents get routed.
Never blocks youIf Horsy fails or is slow, everything runs as before.
Local and fastRouting runs on your machine in tens of milliseconds. Only metadata leaves it.
Down only when cheaperExpected cost and time, retries included, must be lower.
Turns itself offAny task type where it’s losing goes back to your default model.
You stay in control/horsy off, pin a model per task, one-line receipts.
Honest receiptsNet time, net cost, errors caught. Even when negative.
NeutralA model grading itself has a conflict of interest. Horsy is an independent check, and later routes to other providers and local models.
